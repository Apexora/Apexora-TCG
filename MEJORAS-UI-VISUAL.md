# Cartas Alfa — Salto visual 2026

## Dirección de arte
- Fantasía oscura premium: obsidiana, oro martillado, cristal ahumado y acentos carmesí.
- Luminarae conserva el marco dorado y luminoso; Umbra conserva su marco rojo y negro.
- Arena con profundidad, viñeta cinematográfica, círculos arcanos, textura y capas de luz.
- HUD de Nexo y maná con tratamiento de vidrio oscuro, contraste y jerarquía tipográfica.
- Botones con jerarquía más fuerte, estados hover/focus visibles y microinteracciones sutiles.
- Mano, pila de hechizos, bloqueos, chat y editor reciben el mismo sistema visual.
- Responsive para escritorio y móvil, y respeta `prefers-reduced-motion`.

## Alcance
Esta entrega se concentra en la capa visual. No cambia las reglas del motor ni el catálogo de cartas.

## Ejecutar
```bash
npm install
npm run dev
```
